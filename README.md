# Hi there, I'm Vinayak Rajput 👋



## About Me

I am a Software Engineer driven by the challenge of building secure, intelligent, and scalable applications. My journey began with a deep dive into Backend Engineering and Cybersecurity, and it has since evolved into pioneering Android solutions integrated with Generative AI though interest in backend remained same if not grew.



## Why I build:

I believe that the best software is not just functional—it’s proactive. Whether I’m engineering a real-time phishing detection pipeline or architecting an Android app with Gemini-powered intelligence, my goal is to create tools that solve complex problems with elegant code.



## My Core Pillars:

Android & GenAI: Worked on lifecycle of AI-driven mobile apps at MindMatrixEd, using Kotlin and Google AI Studio to build responsive, smart interfaces.



Backend & Scalability: Experienced in developing high-performance web applications with Python (Flask) and Java (Spring Boot), with a focus on optimized data flow and system uptime.



Security-First Mindset: Certified JNCIA-SEC and Google Cybersecurity professional; I treat security as a primary feature, not an afterthought—from Blockchain logs to automated threat classification.



## The Tech I Use:

Languages: Java, Python, Kotlin, SQL, C#.

AI/ML: LSTM, CNN, Prompt Engineering, Gemini API.

Infrastructure: AWS (EC2, S3), Google Cloud, Docker, Git.
